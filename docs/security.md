# Security and privacy

Defaults bind localhost, disable Gradio sharing and analytics, disable the optional monitoring endpoint, queue at most 16 requests, and serialize model access. No external inference API is used. Model preparation and dependency installation access the network; ordinary inference uses prepared local models. Public deployment needs separate authentication, request/rate controls, transport security, and operational review. This starter does not provide those facilities.

Images are checked by decoded format rather than extension, with upload byte and pixel limits before full decode, Pillow decompression-bomb handling, EXIF orientation correction, and RGB conversion. Files larger than the configured limit are rejected. Audio file metadata is checked before decoding; WAV/FLAC format, duration, sample rate, channels, and decoded sample counts are bounded. Samples must be finite; integer PCM is scaled correctly, channels are averaged, and polyphase resampling preserves duration. Invalid numeric embeddings, zero vectors, and dimension mismatches are errors.

Gradio enforces the configured upload-byte limit at launch. It stages uploads and rendered outputs in its own temporary cache, checked for cleanup every 300 seconds with an age threshold of 600 seconds. The runner separately retains at most 16 annotation PNGs in an owned temporary directory, deleted on runner close/process exit. Annotation downloads may expire after newer requests. Abrupt termination may leave OS temporary files. These bounds do not constitute a total process/disk quota under arbitrary hostile traffic.

The toolkit does not log transcripts or image/audio contents. Media remains local, but temporary caching means it is not memory-only processing. Do not treat Gradio's temporary storage as archival. Avoid entering confidential data in public instances. Native inference is synchronous and cannot safely be forcibly interrupted; queue bounds are not execution deadlines.

Gallery imports reject symlink escapes and unsafe relative paths. Loading checks manifest size/schema, matrix size/shape/dtype, finiteness, normalization, unique entries, and pipeline compatibility. NumPy uses `allow_pickle=False`. UI gallery selection is restricted to the configured gallery directory's siblings. The source-root field and local manifests are trusted administrator data; do not accept arbitrary uploaded indexes. Moving or deleting source images requires rebuilding. Gradio receives decoded image previews and individual artifact paths, never an allowed directory containing model weights.

Adapters are trusted application code, registered explicitly; YAML cannot import arbitrary modules. Only selected official PyTorch weight URLs are acquired, cached bytes are SHA256 verified, and Torch uses `weights_only=True`. Whisper acquisition selects Systran repositories and records the resolved snapshot; CTranslate2 loads local converted weights. Local model directories are also trusted and their provenance must be reviewed. Do not load untrusted checkpoints. No pickle-based gallery format or arbitrary model-code execution is supported.

Model execution errors retain local tracebacks for debugging while the UI returns a generic model-failure message. Input/configuration errors provide actionable text and may mention local filenames. No hard memory quotas, multi-tenant isolation, or enterprise security claims are made.
